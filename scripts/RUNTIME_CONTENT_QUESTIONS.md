## 1. world.weather（无来源，已省略）

- **语义规格**要求 `world.weather` 字段；但编年史中天气只散见于切片正文 prose（如「秋阳清澄，气温回升至19℃左右」、个别切片的 `**气象**` 行），无结构化约定。
- **当前实现**：`world.weather` 不输出。
- **请确认**：是否在切片标准格式（编年史卷首「事件结构与记叙标准格式」）中新增结构化行，如 `* **气象**: …`？若新增，exporter 一行解析即可接入；历史切片无该行时保持省略。

## 2. 编年史卷首「编撰宪章」是否属 grounded knowledge

- 02 卷首的「0\. 主世界事件生成与编撰宪章」（Canon Alignment / Grounding Protocol / 标准格式三节）是**编辑规范**而非世界事实。
- **当前实现**：切片边界之前的 preamble 一律不导出（宪章随之排除）。
- **请确认**：宪章是否应保持 non-grounded？（注：Flesh 通过 runtime 拿到它并无害处，但它会占据 context 且非世界事实。）

## 3. World Info 首节「置顶全局核心准则速查」

- 其中含「每人每天最多读写一次共享日记」等**对 Flesh/沙盘的运维公约**。这些规则是写给创作流程的，进入 Flesh 的 RAG 语料后可能被角色当成剧情内事实引用。
- **当前实现**：按小节原样导出（未做特判）。
- **请确认**：a) 该节是否整体保留；b) 运维公约性质的条目是否需要内容侧重写为世界内表述或标记排除。

## 4. 档案小节形态不一致（仅影响导出粒度，不影响正确性）

- 祥子档案用 `## 5\.\n当前形态状态机` 等混级标题，其他档案用 `# **2\.…**`；demux 追加段为 `# **## 4. …**` 异常形态（demux 写入 bug，属内容/脚本归属问题，不归本轮）。
- **当前实现**：`#`/`##` 均视为小节边界，兼容三种形态；「当前形态状态机」按标题文字匹配。
- **请确认**：是否要求各档案小节层级标准化（标准化后 exporter 不需改动，粒度会更整齐）。

## 5. persona_state 数值域扩展

- **语义规格**：`allowed_values: ["white","black"]`，仅祥子档案含状态机小节，故其余 10 人无 `persona_state` 字段（省略而非合成）。
- **请确认**：其余成员未来是否引入 persona_state？若是，取值域与档案书写格式需内容侧定义（exporter 的 white/black 判定目前按祥子专属逻辑硬编码，扩展时需同步）。

## 6. world.title 语义

- **当前实现**：取锚点切片标题的「事件名」部分（如「周一午休·三校学园作息与走廊微澜」）。
- **请确认**：`world.title` 的预期语义是否即「当前世界事件名」；若期望是固定站点名/世界名，请给出取值来源。

## 7. 沙盘/地图与 runtime 解耦（已满足，告知即可）

- `06-全景沙盘` 整体不在导出范围内；后续地图界面（沙盘 UI、roster、landmark、演进日志）如何改动都不影响 runtime 内容获取。内容侧迭代沙盘时无需考虑 Flesh。

## 8. recent_events 摘要口径

- **当前实现**：切片正文机械截断 120 字符（仅剥 markdown 排版符号），非改写、非 LLM 摘要；默认 5 条。
- **请确认**：截断式摘要是否可接受；若需要「叙事级摘要」，须由内容侧在切片标准格式中新增结构化一行（如 `* **一句话摘要**: …`），exporter 优先取用、缺失时回退截断——不做 LLM 补齐。
